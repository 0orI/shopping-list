Shopping List

A simple console-based shopping list application written in Python.

Features

* Add products to a shopping list.
* Prevent duplicate entries.
* Search for products by full or partial name.
* Display all matching products.
* Remove products from the list.
* Handle attempts to remove nonexistent products.
* Display the final shopping list.
* Normalize user input by removing extra spaces and converting text to lowercase.

Technologies

* Python 3
* Standard Python library (no external dependencies)

How to Run

1. Install Python 3.
2. Download shopping_list.py.
3. Open a terminal in the folder containing the file.
4. Run:
    python shopping_list.py
5. Follow the instructions in the terminal.

Notes

* Product quantities can be included in product names, for example: milk 3 pcs.
* Searching supports partial names.
* Removing a product requires entering its full name.
* Product counts and menu options must be entered in the requested format.

Project Purpose

This educational project was developed to practice Python fundamentals, including variables, lists, loops, conditional statements, user input, string methods, and basic program logic.
